\begin{abstract}
This report derives, from first principles, the exact mathematical model and numerical methods implemented in the current APOGEE codebase (\texttt{packages/apogee-core/src/apogee\_core}). The simulator propagates a planar (2D) Earth-centered ascent with variable mass, non-constant gravity, US Standard Atmosphere 1976 (USSA76) density and speed of sound, and aerodynamic drag. Flight is modeled as a hybrid dynamical system with event-driven phase changes (pitch-over, stage-1 burnout and separation, coast, stage-2 burn termination by time or fuel depletion, and ground impact).

The circular-orbit insertion problem is solved via a shooting method that adjusts a four-dimensional control vector $\bm u=(\theta_0, t_{\mathrm{coast}}, t_{\mathrm{burn2}}, \alpha_2)$ and drives a three-component residual based on terminal osculating orbital elements: $\bm F(\bm u)=[(a-r_{\mathrm{target}})/r_{\mathrm{target}},\ e,\ \gamma]^T$. The nonlinear solve is performed with a Levenberg--Marquardt-type iteration using a finite-difference Jacobian in an unconstrained variable $\bm x\in\mathbb{R}^4$ (logistic re-parameterization to enforce bounds), a Broyden rank-1 update, and a backtracking line search.

Every equation and every numerical method is explicitly mapped to the corresponding implementation function and file, to avoid ambiguity.
\end{abstract}

\section{Problem statement}
\subsection{Mission inputs}
The simulator mission is parameterized by:
\begin{itemize}
\item Target circular orbit altitude $h_{\mathrm{target}}$ (m).
\item Payload mass $m_{\mathrm{PL}}$ (kg).
\end{itemize}
Define
\begin{equation}
 r_{\mathrm{target}} = R_E + h_{\mathrm{target}},
\end{equation}
where $R_E$ is the Earth reference radius.

\subsection{Assumptions}
\begin{itemize}
\item Planar (2D) inertial motion; Earth rotation and out-of-plane dynamics are neglected.
\item Central gravity with parameter $\mu$.
\item Two powered stages with constant thrust $T$ and constant specific impulse $I_{sp}$ per stage.
\item Aerodynamic drag with $\rho(h)$ and $a_s(h)$ from USSA76.
\item Hybrid events define phase transitions.
\end{itemize}

\section{State, geometry, and kinematics}
\subsection{State variables}
We define (planar polar coordinates in an inertial plane):
\begin{itemize}
\item $r(t)$: geocentric radius.
\item $\lambda(t)$: downrange central angle (rad).
\item $v(t)$: speed magnitude.
\item $\gamma(t)$: flight-path angle (FPA), measured from local horizontal.
\item $m(t)$: vehicle mass.
\end{itemize}
Altitude is
\begin{equation}
 h(t)=r(t)-R_E.
\end{equation}
The state vector is
\begin{equation}
 \boxed{\bm y(t)=\begin{bmatrix} r(t)\\ \lambda(t)\\ v(t)\\ \gamma(t)\\ m(t) \end{bmatrix}.}
\end{equation}
\textbf{Code:} \texttt{apogee\_core/dynamics.py} (indexing constants \texttt{\_R,\_LAM,\_V,\_GAMMA,\_M}).

\subsection{Velocity decomposition}
In planar polar coordinates,
\begin{equation}
 \bm v = \dot r\,\hat{\bm e}_r + r\dot\lambda\,\hat{\bm e}_{\lambda}.
\end{equation}
Define $\gamma$ such that
\begin{equation}
 \dot r = v\sin\gamma,\qquad r\dot\lambda = v\cos\gamma.
\end{equation}
Therefore the kinematic ODEs are
\begin{equation}
 \boxed{\dot r = v\sin\gamma},\qquad
 \boxed{\dot\lambda = \frac{v\cos\gamma}{r}}.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_general}.

\section{Environment model (USSA76)}
\subsection{Tabulation}
USSA76 provides density $\rho$ and speed of sound $a_s$ as functions of geometric altitude $h$. The code builds a discrete table
\begin{equation}
 z_i = i\,\Delta z,\qquad i=0,\dots,N,\qquad z_N\approx z_{\max},
\end{equation}
and evaluates
\begin{equation}
 \rho_i = \rho(z_i),\qquad a_{s,i} = a_s(z_i).
\end{equation}
\textbf{Code:} \texttt{apogee\_core/atmosphere.py::build\_atmosphere\_table} (cached with LRU).

\subsection{Interpolation and physically safe extrapolation}
During integration, the model uses linear interpolation
\begin{equation}
 \rho(h) = \mathrm{interp}(h;\{(z_i,\rho_i)\}),\qquad a_s(h)=\mathrm{interp}(h;\{(z_i,a_{s,i})\}).
\end{equation}
To avoid non-physical extrapolation above $z_{\max}$, the table is extended with one additional point
\begin{equation}
 z_{N+1} = z_N + \Delta z,\qquad \rho_{N+1}=0,\qquad a_{s,N+1}=a_{s,N},
\end{equation}
so that the interpolator has a C$^0$-continuous approach to vacuum.
\textbf{Code:} \texttt{apogee\_core/atmosphere.py::\_build\_atmosphere\_table\_cached}.

\section{Aerodynamic model}
Define Mach number
\begin{equation}
 M = \frac{v}{a_s(h)}.
\end{equation}
Given a drag coefficient model $C_D(M)$ and reference area $A_{\mathrm{ref}}$, drag magnitude is
\begin{equation}
 \boxed{D = \tfrac12\,\rho(h)\,C_D(M)\,A_{\mathrm{ref}}\,v^2.}
\end{equation}
Dynamic pressure is
\begin{equation}
 \boxed{q = \tfrac12\,\rho(h)\,v^2.}
\end{equation}
\textbf{Code:} \texttt{apogee\_core/dynamics.py::compute\_derived}.

\section{Propulsion and variable mass}
Specific impulse is defined by
\begin{equation}
 I_{sp} = \frac{T}{\dot m_{\mathrm{prop}} g_0}.
\end{equation}
With $\dot m=-\dot m_{\mathrm{prop}}$, mass flow is
\begin{equation}
 \boxed{\dot m = -\frac{T}{I_{sp} g_0}.}
\end{equation}
Coast is implemented by setting $T=0$ and forcing $\dot m=0$.
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_general}, \texttt{rhs\_coast}.

\section{Dynamics: derivation of the implemented ODE}
\subsection{Force model and thrust direction}
Gravity acceleration is central:
\begin{equation}
 \bm a_g = -\frac{\mu}{r^2}\hat{\bm e}_r.
\end{equation}
Let $\hat{\bm t}$ be the unit tangent along velocity and $\hat{\bm n}$ the in-plane normal:
\begin{equation}
 \hat{\bm t}=\sin\gamma\,\hat{\bm e}_r+\cos\gamma\,\hat{\bm e}_{\lambda},\qquad
 \hat{\bm n}=\cos\gamma\,\hat{\bm e}_r-\sin\gamma\,\hat{\bm e}_{\lambda}.
\end{equation}
Let $\alpha$ be the steering angle between thrust and velocity (in-plane). Then
\begin{equation}
 \hat{\bm u}_T = \cos\alpha\,\hat{\bm t} + \sin\alpha\,\hat{\bm n},
\qquad \bm a_T = \frac{T}{m}\hat{\bm u}_T.
\end{equation}
Drag acceleration is opposite velocity:
\begin{equation}
 \bm a_D = -\frac{D}{m}\hat{\bm t}.
\end{equation}

\subsection{Speed equation}
By definition $\dot v = \bm a\cdot \hat{\bm t}$, where $\bm a=\bm a_T+\bm a_D+\bm a_g$. Using
\begin{equation}
 \bm a_T\cdot\hat{\bm t}=\frac{T}{m}\cos\alpha,\qquad \bm a_D\cdot\hat{\bm t}=-\frac{D}{m},\qquad \bm a_g\cdot\hat{\bm t}=-\frac{\mu}{r^2}\sin\gamma,
\end{equation}
we obtain
\begin{equation}
 \boxed{\dot v = \frac{T}{m}\cos\alpha - \frac{D}{m} - \frac{\mu}{r^2}\sin\gamma.}
\end{equation}

\subsection{Flight-path angle equation}
A standard planar identity gives
\begin{equation}
 \bm a\cdot\hat{\bm n} = v\dot\gamma - \frac{v^2}{r}\cos\gamma.
\end{equation}
Compute
\begin{equation}
 \bm a_T\cdot\hat{\bm n}=\frac{T}{m}\sin\alpha,\qquad \bm a_D\cdot\hat{\bm n}=0,\qquad \bm a_g\cdot\hat{\bm n}=-\frac{\mu}{r^2}\cos\gamma.
\end{equation}
Thus
\begin{equation}
 \frac{T}{m}\sin\alpha - \frac{\mu}{r^2}\cos\gamma = v\dot\gamma - \frac{v^2}{r}\cos\gamma,
\end{equation}
and
\begin{equation}
 \boxed{\dot\gamma = \frac{T}{mv}\sin\alpha + \left(\frac{v}{r} - \frac{\mu}{r^2 v}\right)\cos\gamma.}
\end{equation}

\subsection{Complete ODE system (code-consistent)}
Combining kinematics, dynamics, and mass flow:
\begin{align}
 \dot r &= v\sin\gamma,\\
 \dot\lambda &= \frac{v\cos\gamma}{r},\\
 \dot v &= \frac{T}{m}\cos\alpha - \frac{D}{m} - \frac{\mu}{r^2}\sin\gamma,\\
 \dot\gamma &= \frac{T}{mv}\sin\alpha + \left(\frac{v}{r} - \frac{\mu}{r^2 v}\right)\cos\gamma,\\
 \dot m &= -\frac{T}{I_{sp} g_0}.
\end{align}
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_general}.

\section{Numerical regularizations implemented in the RHS}
Two numerical guard terms are implemented to avoid singularities and unstable divisions.

\subsection{Guard for $1/v$}
The $\dot\gamma$ equation contains $1/v$. Near lift-off $v\to 0$, this is numerically singular. The implementation replaces
\begin{equation}
 \frac{1}{v} \;\leadsto\; \frac{v}{v^2 + v_{\varepsilon}^2},
\end{equation}
which matches $1/v$ for $v\gg v_{\varepsilon}$ and remains bounded at $v=0$.
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_general} (variable \texttt{inv\_v}).

\subsection{Guard for $1/r$}
The kinematic and dynamic terms include $1/r$ and $1/r^2$. To avoid numerical collapse if $r$ becomes non-physical, the code uses
\begin{equation}
 r_{\mathrm{safe}} = \max(r, 0.99R_E)
\end{equation}
in denominator terms.
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_general} (variable \texttt{r\_safe}).

\section{Hybrid flight phases and event conditions}
The full ascent is a hybrid system assembled from multiple ODE segments.

\subsection{Phase A: vertical ascent}
To avoid the $1/v$ issue at ignition, the vertical phase enforces
\begin{equation}
 \gamma=\frac{\pi}{2},\qquad \dot\gamma=0.
\end{equation}
The pitch-over event triggers when altitude reaches $h_{\mathrm{po}}$:
\begin{equation}
 g_{\mathrm{po}}(\bm y) = (r-R_E) - h_{\mathrm{po}} = 0.
\end{equation}
After the event, an instantaneous reset sets
\begin{equation}
 \gamma^+ = \frac{\pi}{2} - \theta_0.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_cond\_pitch\_over} and \texttt{simulate\_ascent}.

\subsection{Phase B: stage-1 powered gravity turn}
During stage 1, thrust is aligned with velocity:
\begin{equation}
 \alpha=0.
\end{equation}
Stage-1 burnout is modeled by a mass event. First compute propellant consumed during stage 1
\begin{equation}
 m_{1,\mathrm{prop}} = \frac{T_1\,t_{1,\mathrm{burn}}}{I_{sp,1} g_0},
\end{equation}
and define end-of-burn mass
\begin{equation}
 m_{1,\mathrm{end}} = m_0 - m_{1,\mathrm{prop}}.
\end{equation}
The burnout event is
\begin{equation}
 g_{\mathrm{s1}}(\bm y)=m-m_{1,\mathrm{end}}=0.
\end{equation}
Upon separation, a dry-mass drop is applied:
\begin{equation}
 m^+ = m^- - m_{1,\mathrm{dry}}.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_cond\_stage1\_burnout} and separation logic in \texttt{simulate\_ascent}.

\subsection{Phase C: coast}
Coast integrates the same ODE with $T=0$ and enforces $\dot m=0$.
\textbf{Code:} \texttt{apogee\_core/dynamics.py::rhs\_coast} and \texttt{simulate\_ascent}.

\subsection{Phase D: stage-2 burn with constant steering}
Stage 2 uses a constant steering angle
\begin{equation}
 \alpha = \alpha_2.
\end{equation}
The integration stops at either
\begin{itemize}
\item fixed burn duration $t_{\mathrm{burn2}}$, or
\item fuel depletion event at $m=m_{\min}$.
\end{itemize}
The physical minimum mass is
\begin{equation}
 m_{\min} = m_{2,\mathrm{dry}} + m_{\mathrm{PL}},
\end{equation}
and the event is
\begin{equation}
 g_{\mathrm{fuel}}(\bm y) = m - m_{\min} = 0.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_cond\_fuel\_depletion} and stage-2 RHS term \texttt{\_term\_rhs\_stage2\_steer}.

\subsection{Ground impact}
Ground impact is detected by
\begin{equation}
 g_{\mathrm{ground}}(\bm y)=r-R_E=0.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_cond\_ground}.

\section{ODE solver and event root-finding (numerical methods)}
Each segment is integrated with:
\begin{itemize}
\item \textbf{ODE solver:} Tsitouras 5(4) (\texttt{diffrax.Tsit5}).
\item \textbf{Adaptive step-size controller:} PID controller (\texttt{diffrax.PIDController(rtol,atol)}).
\item \textbf{Event root-finding:} Newton method (\texttt{optimistix.Newton(rtol=root\_rtol, atol=root\_atol)}).
\item \textbf{Saving strategy:} save initial time and every accepted step (\texttt{diffrax.SaveAt(t0=True, steps=True)}).
\end{itemize}
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_solve\_segment}.

\section{Trajectory assembly and time monotonicity}
Segments are concatenated as
\begin{equation}
 t = [t^{(A)}, t^{(B)}_{2:}, t^{(C)}_{2:}, t^{(D)}_{2:}],
\end{equation}
where $2:$ indicates dropping the first sample of each subsequent segment to avoid duplicating boundary points.

Even with this, adaptive solvers and event boundaries can produce consecutive equal times. For physical consistency and frontend consumption, the implementation enforces strict monotonicity
\begin{equation}
 t_{k+1} > t_k\quad\forall k,
\end{equation}
by dropping non-increasing consecutive samples and applying the same mask to all derived series.
\textbf{Code:} \texttt{apogee\_core/simulate.py::\_strictly\_increasing\_mask} and its application to \texttt{ts,ys,mach,drag,q}.

\section{Two-body orbital diagnostics at cutoff}
Given a terminal state $(r,v,\gamma)$ and Earth parameter $\mu$, define specific orbital energy
\begin{equation}
 \varepsilon = \frac{v^2}{2} - \frac{\mu}{r},
\end{equation}
and specific angular momentum magnitude (planar)
\begin{equation}
 h = r v \cos\gamma.
\end{equation}
Eccentricity is computed as
\begin{equation}
 \boxed{e = \sqrt{\max\left\{0,\ 1 + \frac{2\varepsilon h^2}{\mu^2}\right\}}.}
\end{equation}
For bound orbits ($\varepsilon<0$), the semi-major axis is
\begin{equation}
 \boxed{a = -\frac{\mu}{2\varepsilon}.}
\end{equation}
Apoapsis and periapsis radii are
\begin{equation}
 r_a = a(1+e),\qquad r_p=a(1-e).
\end{equation}
\textbf{Code:} \texttt{apogee\_core/orbit.py::orbit\_diagnostics}.

\section{Shooting formulation (current implementation)}
\subsection{Decision variables}
The shooting solver adjusts the control vector
\begin{equation}
 \boxed{\bm u = \begin{bmatrix}\theta_0\\ t_{\mathrm{coast}}\\ t_{\mathrm{burn2}}\\ \alpha_2\end{bmatrix}.}
\end{equation}
\textbf{Code:} \texttt{apogee\_core/shooting.py::solve\_circular\_orbit} and \texttt{compute\_residuals}.

\subsection{Map from controls to terminal orbit}
Given $\bm u$, the code runs a fast terminal-only simulation (same hybrid model) to obtain a terminal state $\bm y_f(\bm u)$.
\textbf{Code:} \texttt{apogee\_core/simulate.py::simulate\_ascent\_final}.

From $\bm y_f$ it computes terminal $(a(\bm u), e(\bm u))$ using the two-body formulas.

\subsection{Residual definition}
The residual implemented is
\begin{equation}
 \boxed{\bm F(\bm u) = \begin{bmatrix}
 \dfrac{a(\bm u)-r_{\mathrm{target}}}{r_{\mathrm{target}}}\\
 e(\bm u)\\
 \gamma(\bm u)
 \end{bmatrix}.}
\end{equation}
Rationale:
\begin{itemize}
\item A circular orbit at radius $r_{\mathrm{target}}$ has $a=r_{\mathrm{target}}$.
\item Circularity requires $e=0$.
\item Tangency at insertion requires $\gamma=0$.
\end{itemize}
\textbf{Code:} \texttt{apogee\_core/shooting.py::compute\_residuals}.

\section{Numerical method for shooting}
\subsection{Bound constraints and logistic re-parameterization}
Physical bounds are enforced:
\begin{equation}
 \theta_0\in[\theta_{\min},\theta_{\max}],\quad t_{\mathrm{coast}}\in[0,200],\quad t_{\mathrm{burn2}}\in[50,450],\quad \alpha_2\in[\alpha_{\min},\alpha_{\max}].
\end{equation}
To solve in $\mathbb{R}^4$, introduce $\bm x\in\mathbb{R}^4$ and
\begin{equation}
 u_i(x_i)=u_{i,\min} + (u_{i,\max}-u_{i,\min})\,\sigma(x_i),
\qquad \sigma(x)=\frac{1}{1+e^{-x}}.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/shooting.py::\_u\_from\_x}, \texttt{\_x\_from\_u}.

\subsection{Finite-difference Jacobian in \texorpdfstring{$\bm x$}{x}}
Let $\bm f(\bm x)=\bm F(\bm u(\bm x))$. A forward-difference Jacobian is computed as
\begin{equation}
 J_{:,i} \approx \frac{\bm f(\bm x+\Delta x_i\,\bm e_i)-\bm f(\bm x)}{\Delta x_i}.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/shooting.py::\_fd\_jacobian\_x}.

\subsection{Levenberg--Marquardt step with backtracking}
At iteration $k$, the code solves the damped normal equations
\begin{equation}
 (J_k^T J_k + \lambda_k I)\,\Delta\bm x_k = -J_k^T \bm f_k,
\end{equation}
tries a finite set of step lengths $\alpha\in\{1,\tfrac12,\tfrac14,\dots\}$, and accepts the first $\alpha$ satisfying strict decrease in $\|\bm f\|_2$.
\textbf{Code:} \texttt{apogee\_core/shooting.py::\_newton}.

\subsection{Broyden rank-1 update}
After an accepted step $\bm s=\bm x_{k+1}-\bm x_k$ and $\bm y=\bm f_{k+1}-\bm f_k$,
\begin{equation}
 J_{k+1}=J_k+\frac{(\bm y-J_k\bm s)\bm s^T}{\bm s^T\bm s}.
\end{equation}
This reduces expensive residual evaluations.
\textbf{Code:} \texttt{apogee\_core/shooting.py::\_broyden\_update}.

\subsection{Multistart candidate generation and scoring}
Candidates are generated from a seed and coarse grids for each control variable, then scored by $\|\bm F(\bm u_0)\|_2$ to select the best initializations.
\textbf{Code:} candidate generation in \texttt{apogee\_core/shooting.py} near \texttt{theta0\_grid, t\_coast\_grid, t\_burn2\_grid, alpha2\_grid}.

\subsection{Convergence criteria}
The implementation checks component-wise tolerances and an overall norm tolerance:
\begin{equation}
 |F_1|<\varepsilon_1,\quad |F_2|<\varepsilon_2,\quad |F_3|<\varepsilon_3
 \quad\text{or}\quad \|\bm F\|_2<\varepsilon.
\end{equation}
\textbf{Code:} \texttt{apogee\_core/shooting.py::\_ok} and \texttt{\_ok\_norm}.

\section{Serialization: JSON trajectory output}
The function \texttt{trajectory\_to\_dict} returns JSON-serializable arrays with explicit unit suffixes:
\begin{itemize}
\item \texttt{t\_s}, \texttt{r\_m}, \texttt{h\_m}, \texttt{lambda\_rad}, \texttt{v\_mps}, \texttt{gamma\_rad}, \texttt{m\_kg}, \texttt{q\_pa}, \texttt{mach}, \texttt{drag\_n}.
\item \texttt{pos\_m}: planar $(x,y,z)$ with $z=0$.
\item \texttt{vel\_mps}: planar $(v_x,v_y,v_z)$ with $v_z=0$.
\item \texttt{orbit}: scalar two-body diagnostics.
\end{itemize}
\textbf{Code:} \texttt{apogee\_core/trajectory.py::trajectory\_to\_dict}.

\section{Calibration module (implemented, but auxiliary)}
The repository also contains a calibration routine in \texttt{apogee\_core/calibration.py}. It defines an outer optimization problem (SciPy L-BFGS-B) over a small parameter vector (e.g., $I_{sp,1}$, $I_{sp,2}$, $t_{1,\mathrm{burn}}$, constant $C_D$ value), while calling the shooting solver as an inner loop.

This module is not required for running the simulator/shooting pipeline, but it is part of the implemented code and therefore documented here.
