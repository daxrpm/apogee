\begin{abstract}
This report details the mathematical models and numerical algorithms governing the \textbf{Apogee} space mission simulator. The system models the ascent of a two-stage liquid-propellant rocket into a circular Low Earth Orbit (LEO) considering variable mass, non-constant gravity, and atmospheric drag based on the US Standard Atmosphere 1976 (USSA76). The flight is modeled as a hybrid dynamical system with discrete event-driven phase transitions. The trajectory optimization problem is solved using a custom implementation of a Levenberg-Marquardt algorithm with Broyden rank-1 updates. This document serves as the authoritative reference for the codebase; all equations are numbered and explicitly mapped to their software implementations.
\end{abstract}

\section{Project Structure and Architecture}

The \texttt{Apogee} project is organized as a monorepo using \texttt{uv} workspaces to ensure modularity and clean separation of concerns.

\begin{description}
    \item[\texttt{packages/apogee-physics}] The core numerical engine.
    \begin{itemize}
        \item \texttt{dynamics.py}: Contains the Equations of Motion (EOM) derived in Section \ref{sec:eom}.
        \item \texttt{atmosphere.py}: Implements the USSA76 atmospheric model (Section \ref{sec:atmosphere}).
        \item \texttt{simulate.py}: Manages the hybrid system integration and event handling (Section \ref{sec:hybrid}).
        \item \texttt{shooting.py}: Implements the optimization algorithms (Section \ref{sec:optimization}).
        \item \texttt{orbit.py}: Calculates Keplerian orbital elements (Section \ref{sec:orbit}).
    \end{itemize}
    \item[\texttt{packages/apogee-launch}] The simulation runner and CLI tools.
    \item[\texttt{packages/apogee-api}] A FastAPI backend for serving simulation results.
    \item[\texttt{packages/apogee-orbit}] Future module for long-term orbit propagation and perturbations.
\end{description}

\section{Coordinate System and State Vector}

We define the motion in a 2D inertial plane centered at the Earth. We assume a non-rotating Earth for the ascent phase purely to simplify the equations to a planar model, although the physics engine is extensible.

The state vector $\bm{y}(t)$ consists of 5 variables:
\begin{equation}
    \label{eq:state_vector}
    \bm{y}(t) = \begin{bmatrix} r(t) \\ \lambda(t) \\ v(t) \\ \gamma(t) \\ m(t) \end{bmatrix}
\end{equation}
Where:
\begin{itemize}
    \item $r(t)$: Geocentric radius (distance from Earth center) [m].
    \item $\lambda(t)$: Downrange central angle [rad].
    \item $v(t)$: Velocity magnitude (speed) [m/s].
    \item $\gamma(t)$: Flight-path angle (FPA), measured from the local horizontal [rad]. $\gamma > 0$ implies ascent.
    \item $m(t)$: Vehicle total mass [kg].
\end{itemize}

\section{Equations of Motion (EOM)}
\label{sec:eom}

\subsection{Kinematics}
From the definition of polar coordinates, the velocity vector $\bm{v}$ can be decomposed into radial ($\hat{e}_r$) and tangential ($\hat{e}_\lambda$) components:
\begin{equation}
    \bm{v} = v \sin\gamma \, \hat{e}_r + v \cos\gamma \, \hat{e}_\lambda
\end{equation}
This yields the kinematic differential equations:
\begin{equation}
    \label{eq:dr}
    \frac{dr}{dt} = v \sin\gamma
\end{equation}
\begin{equation}
    \label{eq:dlam}
    \frac{d\lambda}{dt} = \frac{v \cos\gamma}{r}
\end{equation}

\subsection{Forces}
The vehicle is subject to three primary forces:
\begin{enumerate}
    \item \textbf{Thrust ($T$)}: Acts along the vehicle's longitudinal axis. The steering angle $\alpha$ is defined as the angle between the thrust vector and the velocity vector.
    \item \textbf{Drag ($D$)}: Acts opposite to the velocity vector.
    \item \textbf{Gravity ($g$)}: Acts towards the center of the Earth.
\end{enumerate}

\subsection{Dynamics Derivation}
Newton's Second Law in the path coordinate system (tangent $\hat{t}$ and normal $\hat{n}$ to the trajectory) states:
\begin{align}
    \sum F_t &= m \frac{dv}{dt} \\
    \sum F_n &= m v \frac{d\gamma}{dt} - m \frac{v^2}{r} \cos\gamma \quad \text{(includes centrifugal term)}
\end{align}

Resolving forces:
\begin{itemize}
    \item \textbf{Tangential}: Thrust component $T \cos\alpha$, Drag $-D$, Gravity component $-mg \sin\gamma$.
    \item \textbf{Normal}: Thrust component $T \sin\alpha$, Gravity component $-mg \cos\gamma$.
\end{itemize}

Substituting $g = \mu / r^2$, we obtain the dynamic equations:

\textbf{Speed Equation:}
\begin{equation}
    \label{eq:dv}
    \frac{dv}{dt} = \frac{T}{m} \cos\alpha - \frac{D}{m} - \frac{\mu}{r^2} \sin\gamma
\end{equation}

\textbf{Flight-Path Angle Equation:}
\begin{equation}
    \label{eq:dgamma}
    \frac{d\gamma}{dt} = \frac{T}{m v} \sin\alpha + \left( \frac{v}{r} - \frac{\mu}{r^2 v} \right) \cos\gamma
\end{equation}

\subsection{Mass Flow}
The mass depletion is governed by the rocket equation:
\begin{equation}
    \label{eq:dm}
    \frac{dm}{dt} = - \frac{T}{I_{sp} g_0}
\end{equation}
where $I_{sp}$ is the specific impulse [s] and $g_0$ is standard gravity ($9.80665$ m/s$^2$).

\subsection{Numerical Regularization}
\label{sec:regularization}
Equations (\ref{eq:dgamma}) contains terms with $1/v$. At launch ($t=0, v=0$), this causes a singularity. In the code implementation (\texttt{dynamics.py}), we apply a regularization technique.

We introduce a small epsilon velocity $v_\epsilon$. We define a regularized inverse velocity:
\begin{equation}
    \label{eq:inv_v_reg}
    \frac{1}{v}_{\text{reg}} = \frac{v}{v^2 + v_\epsilon^2}
\end{equation}
This term behaves like $1/v$ for large $v$, but goes to $0$ as $v \to 0$, preventing numerical explosion.

We also guard against $r \to 0$ (though physically impossible in flight) using:
\begin{equation}
    \label{eq:r_safe}
    r_{\text{safe}} = \max(r, 0.99 R_E)
\end{equation}

The implemented regularized $\dot{\gamma}$ equation is:
\begin{equation}
    \label{eq:dgamma_reg}
    \frac{d\gamma}{dt} \approx \frac{T \sin\alpha}{m} \left(\frac{1}{v}_{\text{reg}}\right) + \left( \frac{v}{r_{\text{safe}}} - \frac{\mu}{r_{\text{safe}}^2} \left(\frac{1}{v}_{\text{reg}}\right) \right) \cos\gamma
\end{equation}

\section{Atmosphere and Aerodynamics}
\label{sec:atmosphere}

\subsection{US Standard Atmosphere 1976}
We compute air density $\rho(h)$ and speed of sound $a_s(h)$ using the USSA76 model. The implementation builds a lookup table and uses linear interpolation.
\begin{equation}
    \label{eq:rho_interp}
    \rho(h) = \text{Interp}(h, \text{USSA76}_{\rho})
\end{equation}

\subsection{Aerodynamic Drag}
The Mach number is $M = v / a_s(h)$. The drag force is:
\begin{equation}
    \label{eq:drag}
    D = \frac{1}{2} \rho v^2 C_D(M) A_{\text{ref}}
\end{equation}
where $C_D(M)$ is the drag coefficient (potentially varying with Mach number) and $A_{\text{ref}}$ is the vehicle reference area.

\section{Hybrid System Simulation}
\label{sec:hybrid}

The flight is modeled as a sequence of phases, each governed by specific constraints or parameters.

\subsection{Phase A: Vertical Ascent}
\begin{itemize}
    \item \textbf{Constraint}: $\gamma = \pi/2$ (constant).
    \item \textbf{Dynamics}: $\dot{\gamma} = 0$. $\dot{\lambda} = 0$.
    \item \textbf{Termination Event}: Altitude reaches $h_{\text{pitchover}}$.
    \item \textbf{Transition}: Instantaneous change of $\gamma$ to $\pi/2 - \theta_0$.
\end{itemize}

\subsection{Phase B: Gravity Turn (Stage 1)}
\begin{itemize}
    \item \textbf{Control}: $\alpha = 0$ (Thrust aligned with velocity).
    \item \textbf{Dynamics}: Full EOM (\ref{eq:dr}-\ref{eq:dm}).
    \item \textbf{Termination Event}: Mass reaches $m_{1,\text{end}}$ (Stage 1 burnout).
    \item \textbf{Transition}: Stage separation ($m \to m - m_{1,\text{dry}}$).
\end{itemize}

\subsection{Phase C: Coast}
\begin{itemize}
    \item \textbf{Control}: $T = 0$, $\dot{m} = 0$.
    \item \textbf{Dynamics}: Ballistic motion (Drag + Gravity).
    \item \textbf{Termination Event}: Time duration $t_{\text{coast}}$ elapses.
\end{itemize}

\subsection{Phase D: Stage 2 Burn}
\begin{itemize}
    \item \textbf{Control}: $\alpha = \alpha_2$ (Constant steering angle).
    \item \textbf{Termination Event}: Time duration $t_{\text{burn2}}$ or Fuel Depletion.
\end{itemize}

\section{Numerical Methods}
\label{sec:numerical_methods}

\subsection{Integration (Tsit5)}
We use the \textbf{Tsitouras 5(4)} method, an explicit Runge-Kutta method. It is an adaptive step-size solver.
\begin{itemize}
    \item \textbf{How it works}: It computes the solution at $t + \Delta t$ using a 5th-order formula and a 4th-order formula. The difference between these two estimates provides an error estimate.
    \item \textbf{Adaptivity}: If the error is greater than the tolerance (\texttt{rtol}, \texttt{atol}), the step size $\Delta t$ is reduced. If the error is very small, $\Delta t$ is increased to speed up computation.
\end{itemize}

\subsection{Event Handling (Newton-Raphson)}
To detect events (like reaching a specific altitude), we solve $g(\bm{y}, t) = 0$.
The solver steps over the event (where $g$ changes sign) and then uses the \textbf{Newton-Raphson} method to iteratively find the exact time $t^*$ where $g(t^*) = 0$.

\section{Orbital Mechanics}
\label{sec:orbit}
At injection, we calculate the osculating orbital elements:

\textbf{Specific Mechanical Energy:}
\begin{equation}
    \label{eq:energy}
    \varepsilon = \frac{v^2}{2} - \frac{\mu}{r}
\end{equation}

\textbf{Specific Angular Momentum:}
\begin{equation}
    \label{eq:ang_mom}
    h_{\text{ang}} = r v \cos\gamma
\end{equation}

\textbf{Eccentricity:}
\begin{equation}
    \label{eq:eccentricity}
    e = \sqrt{1 + \frac{2 \varepsilon h_{\text{ang}}^2}{\mu^2}}
\end{equation}

\textbf{Semi-major Axis:}
\begin{equation}
    \label{eq:semi_major}
    a = - \frac{\mu}{2 \varepsilon}
\end{equation}

\section{Optimization Algorithm (Shooting Method)}
\label{sec:optimization}

We wish to find the control parameters $\bm{u}$ that result in a circular orbit at a specific target altitude.

\subsection{Problem Formulation}
\textbf{Decision Variables ($\bm{u}$):}
\begin{itemize}
    \item $\theta_0$: Initial pitch-over angle.
    \item $t_{\text{coast}}$: Duration of coast phase.
    \item $t_{\text{burn2}}$: Duration of second burn.
    \item $\alpha_2$: Steering angle for second stage.
\end{itemize}

\textbf{Residuals ($\bm{F}(\bm{u})$):}
We want the final state to match:
\begin{equation}
    \label{eq:residuals}
    \bm{F}(\bm{u}) = \begin{bmatrix}
        (a - r_{\text{target}}) / r_{\text{target}} \\
        e \\
        \gamma
    \end{bmatrix} \approx \bm{0}
\end{equation}
This enforces correct altitude ($a=r$), circularity ($e=0$), and zero vertical velocity ($\gamma=0$).

\subsection{Algorithm: Levenberg-Marquardt with Broyden}
This is a root-finding algorithm designed to be robust against poor initial guesses.

\begin{enumerate}
    \item \textbf{Variable Transformation}: We map the bounded physical variables $\bm{u}$ to unbounded variables $\bm{x}$ using a sigmoid function (Eq. \ref{eq:logistic}). This allows the optimizer to work in $\mathbb{R}^n$ without violating physical constraints.
    \begin{equation}
        \label{eq:logistic}
        u_i = u_{\min} + (u_{\max} - u_{\min}) \cdot \sigma(x_i)
    \end{equation}
    
    \item \textbf{Jacobian Calculation}: We compute the sensitivity matrix (Jacobian) $J = \partial \bm{F} / \partial \bm{x}$ using Finite Differences. This tells us how the errors change when we tweak the controls.
    
    \item \textbf{Damped Step (Levenberg-Marquardt)}: instead of a pure Newton step ($\Delta \bm{x} = -J^{-1}\bm{F}$), we solve:
    \begin{equation}
        (J^T J + \lambda I) \Delta \bm{x} = -J^T \bm{F}
    \end{equation}
    $\lambda$ is a damping parameter.
    \begin{itemize}
        \item Large $\lambda$: Behaves like Gradient Descent (slow but reliable).
        \item Small $\lambda$: Behaves like Gauss-Newton (fast convergence near solution).
    \end{itemize}
    
    \item \textbf{Broyden Update}: Re-computing the Jacobian with finite differences is expensive (requires 4+ simulations). We use the Broyden rank-1 update to approximate the new Jacobian based on the change in residuals, saving computation time.
\end{enumerate}
